# PRAVAAH AI

Predictive Risk & Anticipatory Vulnerability Assessment for Hazard Action.

PRAVAAH is an anticipatory disaster-intelligence platform for cyclone and extreme-weather risk across coastal APAC. It combines Google Earth Engine satellite data, meteorological data, geospatial risk modeling, Gemini reasoning, scenario simulation, and 3D terrain visualization.

## Current state
- S0 architecture: established
- S1 data foundation: in progress
- Historical replay: Cyclone Michaung (2023)
- Initial geography: coastal Andhra Pradesh
- 3D visualization: dedicated workstream

## Architecture
Data Sources → Data Fusion → Hazard Engine → Exposure → Vulnerability/Risk → Scenario Engine → Anticipatory Action → Gemini → Dashboard/3D → Validation

## Core principle
Deterministic/geospatial/model layers calculate numerical facts. Gemini explains and communicates grounded results; it does not invent or override risk calculations.
