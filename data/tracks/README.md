# Michaung Track Data

Place the NOAA/NCEI IBTrACS v04r01 North Indian basin CSV subset here as:

`CYCLONE_MICHAUNG_2023.csv`

The repository intentionally does not fabricate or manually interpolate cyclone truth. Download the official IBTrACS v04r01 data from NOAA/NCEI and filter the 2023 MICHAUNG record identified by storm ID `2023334N08088`.

Expected required columns:
- ISO_TIME
- LAT
- LON
- USA_WIND
- USA_PRES

Source: NOAA/NCEI IBTrACS v04r01.
