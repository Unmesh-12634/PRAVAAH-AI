# PRAVAAH AI — System Architecture

## End-to-end flow
1. External data sources
2. Data capture and metadata
3. Spatial/temporal normalization
4. Feature generation
5. Hazard modeling
6. Exposure mapping
7. Vulnerability and risk scoring
8. Scenario simulation
9. Anticipatory action prioritization
10. Gemini grounded intelligence
11. 2D dashboard + 3D scenario visualization
12. Validation against historical observations

## Boundary principle
The model layer is the source of numerical facts. Gemini is a grounded reasoning and communication interface over those facts.

## Initial event
Cyclone Michaung (2023).

## Initial AOI
Coastal Andhra Pradesh with surrounding geography required for cyclone approach and impact pathways.
